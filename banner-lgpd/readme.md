 Banner LGPD — Clínica Vida

Este projeto é um banner de consentimento de cookies desenvolvido em conformidade com a LGPD, criado para simular o painel de privacidade do site da Clínica Vida.

 🌐 Link de Acesso
 [Acesse o projeto publicado no GitHub Pages](https://seu-usuario.github.io/nome-do-repositorio/)

 📋 Sobre o Projeto
O banner aparece automaticamente na primeira visita do usuário e oferece opções para gerenciar o rastreamento de dados:
1. Aceitar todos: Ativa os cookies essenciais, de análise e de marketing.
2. Apenas essenciais: Mantém apenas os cookies estritamente necessários ativos.
3. Salvar seleção: Permite escolher individualmente quais categorias ativar por meio de checkboxes.

O projeto também possui um painel de status em tempo real e um botão de "Reabrir preferências" para que o usuário possa alterar suas escolhas a qualquer momento.

 🍪 Categorias de Cookies
Essenciais: Sempre ativos (gerenciados pelo sistema).
Anásise: Controlado pelo cookie "cat_analise" (sim ou nao).
Marketing: Controlado pelo cookie "cat_marketing" (sim ou nao).
Consentimento Geral: Controlado pelo cookie "consentimento_lgpd".
